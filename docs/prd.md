**Version:** 1.0

---

## 1. Product Purpose

BhavishAI is an AI-powered Vedic astrology SaaS that generates personalized 20-page birth chart (Janam Kundli) reports using precise astronomical calculations and AI interpretation. It monetizes the gap between free generic horoscopes and expensive ₹2,000-5,000 astrologer consultations by offering a detailed, personalized report at ₹299.

### Problem Statement

- **For users:** Getting a personalized Vedic astrology reading costs ₹2,000+ and takes days. Generic free horoscopes aren't personalized to exact birth time/place.
- **Market gap:** No product offers a detailed, computationally accurate, instantly-delivered Vedic report at an affordable price point.

### Solution

Enter birth details → get a computationally accurate chart + AI-interpreted 20-page report in 60 seconds for ₹299.

## 2. Target Audience

### Primary: Indian millennials & Gen-Z (18-35)
- Smartphone-first, UPI payment dominant
- Culturally curious about astrology but won't visit a pandit
- Triggered by life transitions: career decisions, marriage questions, relationship confusion
- Acquisition channel: Meta (Instagram/Facebook) ads with UTM tracking

### Secondary: NRI Indians (25-45)
- Living abroad, nostalgic for cultural roots
- Higher willingness to pay
- English-comfortable (product is English + Hindi/Sanskrit terms)

### Anti-Persona (NOT targeting):
- Hardcore astrology believers who want live video consultations
- Western astrology (sun sign only) audiences
- Academic astronomers (they'd critique the Lahiri ayanamsa choice)

## 4. Explicitly Out of Scope (v1)

These are **NOT** being built now. Do not implement unless explicitly requested:

| Feature | Why Out of Scope |
|---------|-----------------|
| Live astrologer chat/video | Completely different business model — we're AI-only |
| Kundli matching (compatibility) | Requires two charts; complex UX; Phase 2 candidate |
| Western astrology (tropical zodiac) | Different audience, different calculations |
| Mobile app (iOS/Android) | Web-first; PWA possible later |
| Multi-language support (Hindi UI) | English serves both Indian + NRI audience |
| Subscription model | One-time purchase is simpler; recurring adds churn mgmt |
| Horoscope predictions (daily/weekly) | Content treadmill; doesn't fit the paid report model |
| Referral/affiliate program | Not enough volume yet to justify complexity |
| A/B testing infrastructure | Use manual deploys + monitor conversion rate |
| Real-time planetary transits | Would require constant recalculation; not part of birth chart |
| Custom report themes/designs | One design serves all; premature optimization |
| WhatsApp/SMS delivery | Email is sufficient; WhatsApp API is expensive |
| Payment plans / EMI | ₹299 is impulse-purchase territory — no need |
| API for third-party developers | No demand signal yet |
| User-generated reviews system | Use static social proof for now |

### Our differentiators:
1. **Computational accuracy** — real astronomy-engine calculations, not pre-computed tables
2. **AI personalization** — references specific planets/houses/degrees in the user's chart
3. **Speed** — 60 seconds vs. days for a human astrologer
4. **Price** — 85% cheaper than a pandit, with comparable depth
5. **Past validation hook** — builds instant trust by resonating with recent life events

## 7. Technical Constraints (Non-Negotiable)

1. **Gemini 3.1-flash-lite** is the only AI model used (cost + speed balance)
2. **Vercel serverless** — max 60s function timeout, no persistent processes
3. **Supabase PostgreSQL** — single database, no Redis/external cache (unless added)
4. **Razorpay only** — no Stripe/PayPal (India-focused, UPI-first)
5. **No user data export** — GDPR-lite compliance via delete-on-request only
6. **All deterministic astrology rules computed in code** — never delegated to AI
